# Mimir

Mimir is the reference implementation of APS Protocol.

This repository is implementation-only and organized as a pnpm workspace.

## Workspace

- `packages/cli`: APS reference CLI implementation.
- `packages/core`: Reserved for shared runtime primitives.
- `packages/generator`: Reserved for generation services.
- `packages/validators`: Reserved for validation components.
- `packages/adapters`: Reserved for provider and platform adapters.
- `packages/schemas`: Reserved for schema and model artifacts.
